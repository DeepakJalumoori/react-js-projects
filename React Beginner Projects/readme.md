# React Beginner Projects

This workspace contains a set of small React projects built with Vite. Each folder is a separate demo focused on one beginner-friendly UI or state management concept.

## Projects

- 01-Counter
- 02-Todo-List
- 03-Meals Api Project
- 04-Calculator
- 05-Color Toggler
- 06-Search Icon
- 07-Testimonials
- 08-Accordion
- 09-Form Validation
- 10.E-Commerce

## How To Run

1. Open the project folder you want to run.
2. Install dependencies if needed:

```bash
npm install
```

3. Start the dev server:

```bash
npm run dev
```

## Notes

- Each project has its own `src` folder and Vite configuration.
- The E-Commerce project includes a sidebar, recommended filters, and a product grid built from shared mock data.
- If you want a README for a specific project, open that folder and I can write one tailored to it.
